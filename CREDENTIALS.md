## 🚀 Quick Start

1. **Open the application** in your browser
2. **Click on the login page** (opens by default)
3. **Choose a role** from the accounts above
4. **Copy the email and password**
5. **Login** and explore the features

---

## 📊 Role-Based Routing

After login, users are automatically redirected based on their role:

- **Super Admin** → `/superadmin` dashboard
- **Branch Head, Doctor, Staff** → `/admin` dashboard
- **Customer** → `/patient-portal` (customer portal)

## 🔒 Security Notes

- These are **demo accounts** for testing purposes
- Passwords are **not encrypted** in mock authentication
- For production, implement:
  - Strong password encryption (bcrypt)
  - JWT token authentication
  - Secure session management
  - Two-factor authentication (2FA)
  - Password reset functionality
  - Account lockout after failed attempts
